# Exploratory Data Analysis – Roller Coaster Dataset

## Overview

This project focuses on Exploratory Data Analysis (EDA) of a roller coaster dataset using Python. The analysis explores coaster characteristics, identifies patterns and relationships, and presents the findings through statistical analysis and visualizations.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains information about **1,087 roller coasters** and **56 features**, including:

* Coaster name
* Speed
* Height
* Manufacturer
* Location
* Type
* Inversions
* G-force
* Year introduced
* Status

## Analysis Performed

* Dataset structure and dimensions
* Missing value analysis
* Duplicate value check
* Statistical summary
* Speed distribution
* Height distribution
* Height vs. speed relationship
* Top 10 fastest roller coasters
* Top manufacturers
* Coaster types
* Inversion distribution
* Coaster status
* Location analysis
* G-force distribution
* Correlation analysis

## Key Insight

The analysis found a strong positive correlation between roller coaster height and speed, with a correlation value of approximately **0.83**.

## Project Files

* `Exploratory_Data_Analysis_Task_3.ipynb` – EDA notebook
* `coaster_db.csv` – Dataset used for analysis

## Conclusion

This project demonstrates the use of Python-based exploratory data analysis techniques to understand patterns, relationships, and trends in a real-world roller coaster dataset.
